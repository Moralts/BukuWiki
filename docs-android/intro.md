# 在 Android 上游玩 Minecraft

:::warning

此章节所谓的 **Android** 指 **使用 Google Android 底层** 系统的 **手机系统**

包括但不限于：

|    手机品牌    |    系统名称     |
| :------------: | :-------------: |
| **OPPO 一加**  |   **ColorOS**   |
|    **真我**    |  **Realme UI**  |
| **vivo IQOO**  |  **OriginOS**   |
| **小米 Redmi** |   **HyperOS**   |
|    **红魔**    | **RedMagic OS** |
|    **三星**    |   **One UI**    |
|    **谷歌**    |  **Pixel UI**   |

以及其他品牌（你可以在开机的时候看开机屏幕下方是不是有 **Powered by Android** 字样）

不适用于：

| 手机品牌 |              系统名称              |
| :------: | :--------------------------------: |
| **华为** | **HarmonyOS 5 （鸿蒙操作系统 5）** |

:::

本章节会为 **Android** 用户提供游玩：

- Minecraft Bedrock Edition
- Minecraft Java Edition（**转译 / 模拟器**）

双版本的游玩教程，玩的愉快 🥵
