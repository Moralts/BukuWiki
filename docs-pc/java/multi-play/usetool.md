# 使用联机工具

本章节将会教会你如何和你的异地朋友在同一个世界中快快乐乐的游玩，异地不在同一局域网怎么办，掏出联机工具，我们马上出发~

:::tip

在这篇教程中，点击 “对局域网开放” 的人则作为 “服务端” ，这个时候你的朋友则需要加入进来，你的朋友则叫做 “客户端”

服务端则需要承担世界运算的工作，你可以选择让你朋友之间设备性能较好的来作为服务端

:::

联机工具千千万，按照目前来说，比较适合和你朋友联机的方式有两种：**虚拟局域网** 和 **内网穿透工具**，各有各的好处， 前者**便宜免费的很多，但流畅度得看每个人的网络质量**，而后者**稳定性好，但需要花一点点钱**，看你如何选择。

我们先来讲讲 **虚拟局域网联机工具** 的使用吧！
