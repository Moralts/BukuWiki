# 局域网联机

本章节将会教会你局域网联机的方式，也就是和你的朋友在同一个 WiFi 下的情况，如何一起联机。

:::tip

在这篇教程中，点击 “对局域网开放” 的人则作为 “服务端” ，这个时候你的朋友则需要加入进来，你的朋友则叫做 “客户端”

服务端则需要承担世界运算的工作，你可以选择让你朋友之间设备性能较好的来作为服务端

:::

如果你和你的朋友在同一个局域网下（或者说你和你的朋友连一个 WiFi），那么你就可以采取直连的方法。

1. 创建主机：

   1. 进入单人存档 → 按 Esc 键 → 点击 「对局域网开放」

   2. 设置游戏模式（生存/创造）和是否允许作弊 → 生成端口号（默认为 19132）。

2. 加入：

   其他玩家在多人游戏界面 → 等待 「本地游戏」 自动刷出主机房间 → 点击加入（无需 IP 输入）。

:::tip

若无法发现房间，检查所有设备是否连接到同一 WiFi，并关闭服务器端的防火墙。

:::


# 常见问题

#### 无效会话

出现类似 `登入失败:null` 或 `无效的会话（请重启启动器或游戏）` 消息提示，无法加入世界。

那这大概率是服务端是正版，而客户端是离线账户，或者相反。

这时候需要禁用 `在线模式` 让不同离线和正版玩家加入服务端的世界。

:::info[解决方案]

1. 安装 [自定义局域网联机](https://www.mcmod.cn/class/2754.html) 模组。
2. 重新创建主机并禁用“在线模式”。
3. 解决。

:::

#### 未知的主机

出现类似 `unknown host` 、 `getsockopt` 或 `未知的主机` 消息提示，无法加入世界。

:::info[可能的情况]

* 没有向局域网开放游戏

:::
